Movimente-se: Esporte e Qualidade de Vida

Sobre o projeto:

-O Movimente-se é um site desenvolvido com o objetivo de apresentar informações sobre esportes e exercícios físicos, destacando seus benefícios para a saúde e a qualidade de vida.

-O projeto busca incentivar a prática de atividades físicas de maneira simples, acessível e informativa.

Objetivos:

-Apresentar diferentes modalidades esportivas.

-Explicar os benefícios dos exercícios físicos.

-Incentivar hábitos mais saudáveis.

-Mostrar alternativas de atividades gratuitas e econômicas.

-Divulgar informações sobre saúde e qualidade de vida.

-Tecnologias utilizadas:

-HTML5

-CSS3

Funcionalidades:

-Navegação entre as páginas.

-Apresentação de diferentes esportes.

-Informações sobre exercícios físicos.

-Benefícios das atividades físicas.

-Dicas para uma vida mais saudável.

Público-alvo:

-Pessoas interessadas em conhecer esportes, praticar exercícios físicos e melhorar sua qualidade de vida.

Estrutura do projeto:

-O projeto é composto por páginas HTML, arquivos CSS responsáveis pela aparência do site e imagens utilizadas na apresentação dos conteúdos.

Considerações finais:

-O projeto foi desenvolvido como atividade acadêmica, colocando em prática os conhecimentos adquiridos em HTML e CSS, com foco na organização, acessibilidade e apresentação das informações.

Projeto desenvolvido para fins educacionais.
